# Career Habits and Goal Setting

Class activities for GTP1202 Career Management, Topic 1.3 (Temasek Polytechnic).

- **WOOP**: students work through Wish, Outcome, Obstacle and Plan, then get a "My WOOP" summary to show, copy or print.
- **Checklist for Career Exploration**: 20 items, totalled automatically and matched to a score band.

Single static page (`index.html`). Answers are stored only in each student's own browser; nothing is sent to a server.
